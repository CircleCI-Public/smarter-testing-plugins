# Smarter Testing plugins

A monorepo for Smarter Testing plugins.

## Available Plugins

### JavaScript/Typescript

- [cypress-circleci-coverage](cypress-circleci-coverage) - A Cypress plugin to generate CircleCI coverage data.
- [jest-circleci-coverage](jest-circleci-coverage) - A Jest plugin to generate CircleCI coverage data.
- [mocha-circleci-coverage](mocha-circleci-coverage) - A Mocha plugin to generate CircleCI coverage data.
- [v8-coverage-collector](v8-coverage-collector) - A V8 plugin to collect coverage data.
- [vitest-circleci-coverage](vitest-circleci-coverage) - A Vitest plugin to generate CircleCI coverage data.

## Python

- [pytest-circleci-coverage](pytest-circleci-coverage) - A pytest plugin to generate CircleCI coverage data.
